# Security Policy

## Supported Versions

Only the latest 7.x release gets security fixes.

| Version | Supported          |
| ------- | ------------------ |
| 7.x     | :white_check_mark: |
| < 7.0   | :x:                |

## Reporting a Vulnerability

Do not open a public issue for a vulnerability.

Report it privately through GitHub: [open a private vulnerability report](https://github.com/code-forge-io/remix-hook-form/security/advisories/new).

We fix the vulnerability, release a new version, and then publish a GitHub security advisory.
